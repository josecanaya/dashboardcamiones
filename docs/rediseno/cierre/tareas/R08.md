## Editar

## Hacer
1. Sidebar: reemplazar grupo Datos y proceso con sus entradas por un único enlace `Datos` → `/estadisticas/datos`. Conservar indicadores, reportes, Home y editor de plano.
2. Ruta nueva usa DataWorkspace. URLs `/estadisticas/datos/extraccion` y `/extraccion` redirigen a `/estadisticas/datos?vista=extraccion-avanzada`; `/estadisticas/datos/analisis-local` y `/analisis-local` redirigen a `/estadisticas/datos?vista=analisis-avanzado`.
3. DataWorkspace lee query `vista` y abre Disclosure correspondiente, sin descargar/procesar al entrar. Rango se conserva en contexto. Valores de vista no reconocidos abren vista normal.
4. Mantener las dos redirecciones Transform → Resumen ejecutivo ya hechas; no reintroducir ruta de proceso.
5. Gate de reportes sin transform: texto «Todavía no hay datos preparados para este período» + Link «Preparar datos» al nuevo hub. Ninguna instrucción manda visitar Transform o cargar el mismo rango otra vez.
6. routeElements puede seguir exportando adaptadores para consumidores legacy, pero no debe navegar a rutas retiradas. Reemplazar sus destinos por los nuevos definidos aquí.
7. Añadir test de PRODUCT_SECTIONS/LEGACY_ROUTE_REDIRECTS: enlace Datos único, sin Transform/Extracción/Análisis en sidebar, targets definidos sin bucles ni duplicados.

## No hacer
- No borrar rutas de producto, editor, Home, reportes ni callbacks internos de herramientas.
- No incluir cambios ajenos de App.tsx en el commit; stagear únicamente el diff de esta tarea.

`npm test -- --maxWorkers=2`, `npm run check:arch`. Abrir cada URL vieja directamente y comprobar destino/herramienta visible. Atrás/adelante no inicia POST y conserva active.
