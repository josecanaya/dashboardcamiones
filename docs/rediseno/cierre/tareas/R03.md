2. Reducer puro con eventos SET_DRAFT, CHECK_STARTED, CHECK_SUCCEEDED, STEP_STARTED, STEP_SUCCEEDED, STEP_FAILED, LOAD_SUCCEEDED, STOPPED, RESTORED. Eventos de operación llevan operationId. Ignorar obsoletos; solo LOAD_SUCCEEDED cambia active. SET_DRAFT no cambia active ni requested.
3. `buildPreparationPlan` recibe rango, días fuente, corridas ya verificadas, cobertura Excel y `lastCompleteDay` explícito. No Date.now/fetch/localStorage dentro de funciones puras.
4. Si vigente cubre rango: una tarea load, ninguna descarga/proceso. Si no: semanas canónicas faltantes; fuentes requeridas según contrato, downloads únicos ordenados y luego process único por semana; load al final.

6. Tests: vigente exacto/compuesto, hueco, stale, parcial, error de fuente, arrastre de domingo, cruce de año, semana abierta hasta ayer, futuro no descargable, Excel desconocido, respuesta de operación vieja y fallo que conserva active.
